# Michael Donoser — Personal Homepage

Personal website of **Michael Donoser, Ph.D.**, author of The Leadership Fork and former Director of Science at Amazon.
Live at: [mike-dono-0815.github.io/homepage](https://mike-dono-0815.github.io/homepage/)

## Content

- **Hero** — Name, role, the book hook and the newsletter signup
- **Why a book, why a newsletter** — The story behind The Leadership Fork, with the Substack signup
- **Two tracks** — Research career (Graz University of Technology) and industry career (Amazon), with research and industry records
- **Coaching** — Six leadership themes with related writing
- **Book** — The Leadership Fork and its five chapters
- **Writing** — Recent essays on Medium and LinkedIn
- **Projects** — Side projects built with AI, each with a live demo
- **Contact** — LinkedIn, Substack, Instagram, TikTok, Medium, GitHub and Google Scholar

The previous design is archived in the `archive/homepage-v1` branch and the `homepage-v1` tag.

## Tech Stack

Plain HTML, CSS, and JavaScript — no frameworks, no build step. Hosted on GitHub Pages.
